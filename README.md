## Sobre

Aplicação fullstack planejada com API Express organizada em camadas, banco de dados SQLite e frontend com Bootstrap e JavaScript puro.

O domínio do projeto é um sistema para auxiliar no gerenciamento de um pet shop, permitindo cadastrar animais, seus tutores e serviços realizados, como banho, tosa e consultas.

## Estrutura

- `s1/` — exercícios da Semana 1: os quatro pilares da POO em JavaScript.
- `s2/S2_library-bad.js` — atividade de identificação de code smells e violações dos princípios SOLID, sem refatoração do código original.
- `MODELAGEM.md` — modelagem conceitual do domínio de pet shop, com diagrama de classes, responsabilidades de serviços e repositórios e explicação dos princípios SRP e DIP.

## Semana 2 — Code Smells, SOLID e Modelagem

### Parte A — Identificação de Code Smells e violações SOLID

O arquivo `s2/S2_library-bad.js` contém comentários que identificam os code smells e as violações de princípios SOLID encontrados no código de exemplo. O código original foi preservado, sem refatoração.

### Parte B — Modelagem

O arquivo `MODELAGEM.md` apresenta a modelagem de um sistema de gerenciamento de pet shop com quatro entidades: `Tutor`, `Animal`, `Servico` e `Agendamento`.

A documentação descreve os relacionamentos entre as entidades, as responsabilidades dos serviços e dos repositórios e a aplicação dos princípios SRP e DIP.
